SETUP INSTRUCTIONS:

1. Save all files in the same directory:
   - index.html
   - history.html
   - divisions.html
   - tourism.html
   - styles.css
   - script.js
   - specification.txt
   - README.txt (this file)

2. Open index.html in a web browser.

3. The website is fully functional offline as it uses CDN links for Bootstrap.

4. Features:
   - Responsive design works on mobile, tablet, and desktop
   - Interactive JavaScript features
   - Bootstrap components throughout
   - Consistent color theme
   - Navigation between all 4 pages

5. Testing:
   - Click through all navigation links
   - Test on different screen sizes
   - Try interactive elements (buttons, forms)
   - Check that all requirements are met

Note: The images are loaded from Unsplash via CDN, so an internet connection is needed for images to display properly.
